Boxotel

Developpement web - Projet scolaire

Intégration et developpement HTML, CSS et JS d’un site d’hotel pour réservation

Voir le site

Qu’est ce que Boxotel?

Boxotel est un travail de refonte de site qui est d'offrir le luxe d'hotêl avec ses plusieurs chambres et ses plusieurs bonus.

Utilisation de l’IA

Le luxe offert pour l'espace détente

Étapes:

1 — Analyse des différentes parties de la maquette sur Figma

Pour commencer, mon partenaire et moi ont analysés et décortiqués la maquette de Boxotel pour définir les sections des pages et ce que nous avons besoin.

2 — Intégration html du site d'hotêl avec VS Code

Suite à notre analyse, nous conçevons avec du code html les pages du site tout en gardant une bonne organisation des sections et des classes.

3 — Ajout du css aux sections et aux classes dans VS Code

Dès que nous avons fini avec l'html, nous poursuivons le progrès en stylisant avec le css les quatre pages du site de Boxotel.

4 — Programmation js et ajustement responsive du site sur VS Code

À la suite des styles, nous poursuivons la construction du site en ajoutant les composantes js appropriées et en ajoutent le responsive dans nos pages.

5 - Résultat final de Boxotel via le navigateur au choix

Maintenant que c’est tout finalisé, nous pouvons survoler le site sur un navigateur pour voir les types de chambres , les bonus de l'espace détente et les détails d'une chambre.
