AudioVerse

Developpement web - Projet scolaire

Intégration et developpement HTML, CSS et JS d’un site de conférences et de conférenciers

Voir le site

Qu’est ce que AudioVerse?

Pour ce projet scolaire, il fallait choisir une thématique de média à mettre en image pour des conférences. Moi, j’ai choisi l’audio . Donc, mon site de conférences et conférenciers se composent de sons et de trames sonore .

Étapes:

1 — Sélection de couleurs et de typographie du site sur Figma

Je poursuis la création de mon site en choisissant une palette de couleur impécable et en choisissant deux excellents typographies qui seront utilisées dans mes maquettes.

2 — Création des maquettes du site et organisation des sections dans Figma

Je conçois une maquette pour 2 différentes pages avec des différentes sections pour mon site web: la page d’accueil et la page du conférencier.

3 — Intégration html et développement css du site de conférences sur VS Code

Suite à la maquette, je conçois avec du code html et css les pages du site tout en gardant une bonne organisation des sections et des classes que j’utilise pour le css.

4 — Programmation js et ajustement responsive du site sur VS Code

Après finaliser le css de base pour mon site, j’ai programmé des composantes et ajusté le responsive de mon site pour que ce soit calibrer pour le mobile.

5 - Résultat final d'AudioVerse via le navigateur au choix

Maintenant que c’est tout finalisé, je peux survoler mon site sur un navigateur pour voir les conférenciers et les conférences fictifs qui sont offerts.
